# Core recipe catalog pack

The reviewed eight-record Wikipedia starter pack is stored separately from app code in [`catalog-packs/iba-wikipedia-starter/`](../../catalog-packs/iba-wikipedia-starter/). Its manifest, source IDs, attribution, CC BY-SA 3.0 notice, and modifications ship with the data. Do not add other candidate records until their exact source entries and redistribution terms have been reviewed.

See the [data source and distribution policy](../../docs/product/MVP_SPEC.md#7-data-source-and-distribution-policy) and [ADR-0006](../../docs/architecture/ADR-0006-separate-catalog-packs-and-import-pipeline.md).
