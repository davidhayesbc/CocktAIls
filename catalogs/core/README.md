# Core recipe catalog pack

This directory is reserved for a separately versioned, offline recipe pack. Keep its manifest, source IDs, attribution, license notices, modifications, and update notes alongside the data. Do not add candidate third-party records until their exact source entries and redistribution terms have been reviewed.

See the [data source and distribution policy](../../docs/product/MVP_SPEC.md#7-data-source-and-distribution-policy) and [ADR-0006](../../docs/architecture/ADR-0006-separate-catalog-packs-and-import-pipeline.md).
