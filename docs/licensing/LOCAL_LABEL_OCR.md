# On-device label text

The Android APK bundles Google's ML Kit Latin text recognizer (`com.google.mlkit:text-recognition:16.0.1`). It is available immediately without a downloaded recognition model; see the official [Android integration](https://developers.google.com/ml-kit/vision/text-recognition/v2/android) and [installation paths](https://developers.google.com/ml-kit/tips/installation-paths). ML Kit is distributed under Google's SDK terms, not the app's source-code license.

Only the retained, user-selected label crop is recognized. Recognition is local. Full OCR text stays in memory and is not included in lookup diagnostics, detailed captures, public CI output, or cloud-provider requests. The optional installed Qwen model receives bounded OCR text plus separately identified barcode-verified web facts as context. The app validates each proposed field against a literal label quote; web context cannot serve as label evidence. Explicit size/ABV facts remain available when the model is absent, abstains, or fails. Conflicting values remain unresolved. Recognition is fallible: glare, curved labels, small print and language need physical-device testing.

Work is bound to a session, bottle draft, photo digest, barcode, queue attempt and replaceable request token. A new crop replaces older work; lookup completion runs label extraction with the latest verified context. Reprocess reruns both stages. Removed/accepted drafts cannot receive late results. Only bounded validated quotes are kept in private preferences while the draft exists; they are removed with its pending evidence, excluded from web provenance exports, and Android backup is disabled. Manual edits and deliberately cleared fields remain authoritative.

The emulator test generates a fictional label and disables Wi-Fi/mobile data for recognition. No user image or OCR transcript is used in CI. Physical-device checks still include glossy/curved labels, rotation, tiny text, foreground/background transitions and memory/battery behavior with the optional 0.6B model.
