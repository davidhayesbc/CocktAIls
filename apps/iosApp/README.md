# iOS application (future)

Planned native iOS app: Swift and SwiftUI, consuming the Kotlin Multiplatform framework built from `shared/core`. Implement Apple-specific camera/barcode, document picker/share sheet, Keychain-backed credential storage, and optional model runtime adapters here.

This target is not part of the first Android release. Building, signing, and device testing it requires macOS and Xcode. See [ADR-0008](../../docs/architecture/ADR-0008-kotlin-multiplatform-repository.md).
