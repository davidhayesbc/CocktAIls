# Android application

Planned native Android app: Kotlin and Jetpack Compose. It will consume `shared/core` for domain, persistence, search, and import/merge behavior, and implement Android-specific camera/barcode, files, secure storage, and optional model runtime adapters.

No Android project code has been scaffolded yet. See [ADR-0008](../../docs/architecture/ADR-0008-kotlin-multiplatform-repository.md) and the [Phase 1 plan](../../docs/planning/PHASE_1_PLAN.md).
